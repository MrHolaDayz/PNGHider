````markdown id="7z2nqp"
# PNGHider

> Простая и безопасная LSB-стеганография для PNG-изображений на Python.

PNGHider позволяет скрывать произвольные данные внутри PNG-файлов без заметных визуальных изменений изображения.

Библиотека использует:

- LSB-стеганографию
- псевдослучайную карту позиций
- zlib-сжатие
- HMAC-проверку целостности
- опциональное шифрование вторым паролем

---

# Возможности

## Скрытие любых данных

Можно скрывать:

- текст
- изображения
- архивы
- бинарные файлы
- ключи
- любые байты

---

## Пароль карты позиций

Пиксели выбираются не подряд, а псевдослучайно.

Порядок зависит от:

- пароля
- содержимого изображения

Без правильного пароля извлечение невозможно.

---

## Опциональное шифрование

Можно использовать второй пароль для шифрования payload.

Поддерживается:

- PBKDF2-HMAC-SHA256
- SHA-512 stream cipher
- HMAC-SHA256

---

## Проверка целостности

Каждый payload защищён через HMAC.

Это позволяет обнаружить:

- неправильный пароль
- повреждение изображения
- изменение скрытых данных

---

## Поддержка RGB и RGBA

Библиотека работает с:

- RGB PNG
- RGBA PNG

Alpha-канал сохраняется.
````

# Быстрый старт

## Скрытие текста

```python id="ecow9t"
from PNGHider import hide

data = b"Hello world"

hide(
    image_path="image.png",
    password="my-password",
    data=data,
)
```

После выполнения данные будут встроены прямо в `image.png`.

---

## Извлечение текста

```python id="dkmwx4"
from PNGHider import extract

data = extract(
    image_path="image.png",
    password="my-password",
)

print(data.decode())
```

# Работа с файлами

## Скрытие файла

```python id="fll4h9"
from PNGHider import hide

with open("secret.zip", "rb") as f:
    payload = f.read()

hide(
    image_path="photo.png",
    password="map-password",
    data=payload,
)
```

---

## Извлечение файла

```python id="rxo4dw"
from PNGHider import extract

data = extract(
    image_path="photo.png",
    password="map-password",
)

with open("restored.zip", "wb") as f:
    f.write(data)
```

# Шифрование данных

По умолчанию PNGHider только скрывает данные.

Чтобы дополнительно защитить payload, можно использовать второй пароль.

---

## Скрытие с шифрованием

```python id="0cljqj"
hide(
    image_path="image.png",
    password="map-password",
    encryption_password="encryption-password",
    data=b"Very secret data",
)
```

---

## Извлечение с шифрованием

```python id="p80vqb"
data = extract(
    image_path="image.png",
    password="map-password",
    encryption_password="encryption-password",
)
```

---

## Что будет при неверном пароле

Если пароль неверный:

* HMAC не совпадёт
* будет выброшено исключение

Пример:


# Параметр depth

```python id="y1k4m1"
hide(..., depth=2)
```

`depth` определяет, сколько младших бит каждого канала используется для хранения данных.

---

# Как depth влияет на изображение

| depth | Вместимость  | Незаметность             |
| ----- | ------------ | ------------------------ |
| 1     | низкая       | почти идеальная          |
| 2     | средняя      | очень высокая            |
| 4     | высокая      | возможны артефакты       |
| 8     | максимальная | изображение повреждается |

---

# Рекомендуемые значения

## Максимальная незаметность

```python id="1m5nvv"
depth=1
```

---

## Баланс

```python id="0r2d47"
depth=2
```

---

## Максимальная вместимость

```python id="wzq1mk"
depth=4
```

или выше.

---

# Вместимость PNG

Приблизительная формула:

```text id="4f0ezv"
(width × height × channels × depth) / 8
```

---

## Пример

Изображение:

```text id="07d0h7"
1920 × 1080
RGB
depth = 2
```

Вместимость:

```text id="h4azxt"
1920 × 1080 × 3 × 2 / 8
≈ 1.5 MB
```

# Как работает PNGHider

## 1. Сжатие

Сначала данные сжимаются через zlib.

Это:

* уменьшает размер payload
* снижает число изменённых пикселей

---

## 2. Шифрование

Если указан `encryption_password`:

* генерируется salt
* создаётся ключ через PBKDF2
* данные шифруются потоковым шифром

---

## 3. HMAC

После этого вычисляется HMAC-SHA256.

Он нужен для проверки:

* правильности пароля
* целостности payload

---

## 4. Генерация карты позиций

Позиции пикселей:

* перемешиваются
* зависят от пароля
* зависят от изображения

Это усложняет обнаружение payload.

---

## 5. Запись битов

Данные записываются в младшие биты каналов:

* R
* G
* B
* A (если есть)

# API

# hide

```python id="jlwmma"
hide(
    image_path: str,
    password: str,
    data: bytes,
    depth: int = 2,
    encryption_password: str | None = None,
) -> None
```

---

## Аргументы

| Аргумент            | Тип        | Описание                   |
| ------------------- | ---------- | -------------------------- |
| image_path          | str        | путь к PNG                 |
| password            | str        | пароль карты позиций       |
| data                | bytes      | скрываемые данные          |
| depth               | int        | число используемых LSB-бит |
| encryption_password | str | None | пароль шифрования          |

---

# extract

```python id="h8q4ib"
extract(
    image_path: str,
    password: str,
    depth: int = 2,
    encryption_password: str | None = None,
) -> bytes
```

Извлекает payload из PNG.

# Ограничения

## PNG only

PNGHider работает только с PNG.

JPEG не подходит, потому что использует lossy-сжатие.

---

## Любое изменение изображения опасно

Следующие операции обычно уничтожают payload:

* resize
* crop
* пересохранение
* конвертация формата
* фильтры
* сжатие

---

## Социальные сети

Большинство платформ:

* перекодируют изображения
* меняют PNG
* уничтожают LSB-данные

---

# Безопасность

PNGHider обеспечивает:

* скрытие данных
* базовую криптографическую защиту
* защиту от случайного повреждения

Но библиотека не заменяет полноценные системы шифрования.

Для критически важных данных используйте:

* age
* PGP
* VeraCrypt
* AES-GCM решения

---

# Производительность

Скорость зависит от:

* размера PNG
* значения depth
* размера payload

Обычно:

* запись занимает доли секунды
* большие изображения требуют больше памяти
