# PNGHider

<div align="center">

### LSB-стеганография для PNG на Python

Скрытие данных внутри PNG-изображений  
с поддержкой шифрования и проверки целостности.

</div>

---

## Возможности

| Возможность | Описание |
|---|---|
| LSB-стеганография | Скрытие данных в младших битах пикселей |
| Пароль позиций | Псевдослучайная карта записи |
| Шифрование | Дополнительная защита вторым паролем |
| HMAC | Проверка целостности данных |
| zlib | Автоматическое сжатие payload |
| RGB / RGBA | Поддержка PNG с alpha-каналом |

---

## Что можно скрывать

- текст
- изображения
- архивы
- документы
- бинарные файлы
- ключи
- любые байтовые данные

---

## Как работает PNGHider

### 1. Сжатие

Данные автоматически сжимаются через `zlib`.

Это:

- уменьшает payload
- снижает число изменённых пикселей
- повышает незаметность

---

### 2. Шифрование (опционально)

Если указан `encryption_password`:

- создаётся salt
- ключ генерируется через PBKDF2-HMAC-SHA256
- payload шифруется потоковым шифром

---

### 3. HMAC-защита

После шифрования вычисляется HMAC-SHA256.

Это позволяет обнаружить:

- неверный пароль
- повреждение PNG
- изменение payload

---

### 4. Генерация карты позиций

Позиции записи:

- перемешиваются псевдослучайно
- зависят от пароля
- зависят от изображения

Без правильного пароля извлечь payload невозможно.

---

### 5. Запись данных

Payload записывается в младшие биты:

- R
- G
- B
- A (если есть)

# Быстрый старт

## Скрытие текста

```python id="ecow9t"
from PNGHider import hide

data = b"Hello world"

hide(
    image_path="image.png",
    password="my-password",
    data=data,
)
```

После выполнения данные будут встроены прямо в `image.png`.

---

## Извлечение текста

```python id="dkmwx4"
from PNGHider import extract

data = extract(
    image_path="image.png",
    password="my-password",
)

print(data.decode())
```

# Работа с файлами

## Скрытие файла

```python id="fll4h9"
from PNGHider import hide

with open("secret.zip", "rb") as f:
    payload = f.read()

hide(
    image_path="photo.png",
    password="map-password",
    data=payload,
)
```

---

## Извлечение файла

```python id="rxo4dw"
from PNGHider import extract

data = extract(
    image_path="photo.png",
    password="map-password",
)

with open("restored.zip", "wb") as f:
    f.write(data)
```

# Шифрование данных

По умолчанию PNGHider только скрывает данные.

Чтобы дополнительно защитить payload, можно использовать второй пароль.

---

## Скрытие с шифрованием

```python id="0cljqj"
hide(
    image_path="image.png",
    password="map-password",
    encryption_password="encryption-password",
    data=b"Very secret data",
)
```

---

## Извлечение с шифрованием

```python id="p80vqb"
data = extract(
    image_path="image.png",
    password="map-password",
    encryption_password="encryption-password",
)
```

---

## Что будет при неверном пароле

Если пароль неверный:

* HMAC не совпадёт
* будет выброшено исключение

Пример:

```python id="3z22d7"
ValueError: HMAC не совпадает.
```

# Параметр depth

```python id="y1k4m1"
hide(..., depth=2)
```

`depth` определяет, сколько младших бит каждого канала используется для хранения данных.

---

# Как depth влияет на изображение

| depth | Вместимость  | Незаметность             |
| ----- | ------------ | ------------------------ |
| 1     | низкая       | почти идеальная          |
| 2     | средняя      | очень высокая            |
| 4     | высокая      | возможны артефакты       |
| 8     | максимальная | изображение повреждается |

---

# Рекомендуемые значения

## Максимальная незаметность

```python id="1m5nvv"
depth=1
```

---

## Баланс

```python id="0r2d47"
depth=2
```

---

## Максимальная вместимость

```python id="wzq1mk"
depth=4
```

или выше.

---

# Вместимость PNG

Приблизительная формула:

```text id="4f0ezv"
(width × height × channels × depth) / 8
```

---

## Пример

Изображение:

```text id="07d0h7"
1920 × 1080
RGB
depth = 2
```

Вместимость:

```text id="h4azxt"
1920 × 1080 × 3 × 2 / 8
≈ 1.5 MB
```

# API

# hide

```python id="jlwmma"
hide(
    image_path: str,
    password: str,
    data: bytes,
    depth: int = 2,
    encryption_password: str | None = None,
) -> None
```

---

## Аргументы

| Аргумент            | Тип        | Описание                   |
| ------------------- | ---------- | -------------------------- |
| image_path          | str        | путь к PNG                 |
| password            | str        | пароль карты позиций       |
| data                | bytes      | скрываемые данные          |
| depth               | int        | число используемых LSB-бит |
| encryption_password | str | None | пароль шифрования          |

    depth: int = 2,
    encryption_password: str | None = None,

# Ограничения

## PNG only

PNGHider работает только с PNG.

JPEG не подходит, потому что использует lossy-сжатие.

---

## Любое изменение изображения опасно

Следующие операции обычно уничтожают payload:

* resize
* crop
* пересохранение
* конвертация формата
* фильтры
* сжатие

---

## Социальные сети

Большинство платформ:

* перекодируют изображения
* меняют PNG
* уничтожают LSB-данные

---

# Безопасность

PNGHider обеспечивает:

* скрытие данных
* базовую криптографическую защиту
* защиту от случайного повреждения

Но библиотека не заменяет полноценные системы шифрования.

Для критически важных данных используйте:

* age
* PGP
* VeraCrypt
* AES-GCM решения

---

# Производительность

Скорость зависит от:

* размера PNG
* значения depth
* размера payload

Обычно:

* запись занимает доли секунды
* большие изображения требуют больше памяти
