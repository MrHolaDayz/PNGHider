# pnghider

Стеганография в PNG: скрывает произвольные байты в младших битах пикселей. Поддерживает запись в один файл или распределение по нескольким PNG.

## Зависимости

```
pip install pillow numpy
```

## Установка

Скопируйте `pnghider.py` в свой проект и импортируйте нужные функции.

## API

### `hide(image_paths, password, data, depth=2)`

Прячет данные в PNG-файле или списке PNG-файлов.

| Параметр | Тип | Описание |
|---|---|---|
| `image_paths` | `str \| list[str]` | Путь к PNG или список путей |
| `password` | `str` | Пароль для генерации карты позиций |
| `data` | `bytes` | Данные для сокрытия |
| `depth` | `int` | Бит на байт пикселя, 1–8 (по умолчанию `2`) |

Если данных больше, чем вмещают переданные файлы, функция интерактивно запросит пути к дополнительным PNG.

---

### `extract(image_paths, password, depth=2)`

Извлекает данные из PNG-файла или списка PNG-файлов.

| Параметр | Тип | Описание |
|---|---|---|
| `image_paths` | `str \| list[str]` | Путь к PNG или список путей |
| `password` | `str` | Должен совпадать с использованным при записи |
| `depth` | `int` | Должен совпадать с использованным при записи |

Возвращает `bytes`. Порядок файлов в списке не важен — чанки собираются по индексам из заголовков.

---

### Параметр `depth`

| `depth` | Бит на пиксельный байт | Видимые изменения |
|---|---|---|
| 1 | 1 | Практически незаметны |
| 2 | 2 | Незаметны (рекомендуется) |
| 4 | 4 | Слабо заметны |
| 8 | 8 | Заметны |

Ёмкость пропорциональна `depth`: при `depth=4` можно спрятать вдвое больше, чем при `depth=2`.

## Примеры

**Текст из файла:**

```python
from pnghider import hide, extract

with open("secret.txt", "rb") as f:
    data = f.read()

hide("image.png", "пароль", data)

result = extract("image.png", "пароль")
print(result.decode("utf-8"))
```

**Произвольные байты:**

```python
hide("image.png", "пароль", bytes([0x00, 0xFF, 0x42]))
```

**Любой файл целиком:**

```python
with open("document.pdf", "rb") as f:
    hide("image.png", "пароль", f.read())
```

**Несколько PNG:**

```python
# Запись
hide(["a.png", "b.png", "c.png"], "пароль", data)

# Чтение (порядок файлов не важен)
result = extract(["c.png", "a.png", "b.png"], "пароль")
```

**Запись с автозапросом файлов:**

```python
# Если data не помещается в a.png — программа спросит путь к следующему файлу
hide("a.png", "пароль", large_data)
```

## Как это работает

Данные сжимаются через zlib и записываются в младшие `depth` бит байтов пикселей. Порядок байтов определяется SHA-512 от пароля и первых 1024 байт пикселей изображения — без пароля восстановить карту позиций невозможно.

При многофайловой записи сжатые данные нарезаются на чанки по фактической ёмкости каждого файла. Каждый чанк содержит заголовок с общим числом чанков и своим индексом, что позволяет собрать данные обратно в любом порядке.

## Ограничения

- Работает только с PNG. JPEG и другие форматы с lossy-сжатием уничтожат данные.
- Файл должен существовать до записи — библиотека не создаёт изображения.
- `depth` и `password` при извлечении должны совпадать с использованными при записи.
